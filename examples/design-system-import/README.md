# Design System Import

A Next.js app demonstrating the v0 Design Systems 2.0 import workflow:

- **Import Wizard** — Add sources (GitHub repos, Figma frames, links, attachments), environment variables, and notes
- **v0.json Editor** — Preview and edit the generated v0.json with reference sources, environment providers, and starter configuration
- **Skill Browser** — View saved design system skills, search, and attach to chats

## Running

```bash
cd examples/design-system-import
bun install
bun run dev
```

Open http://localhost:3000
